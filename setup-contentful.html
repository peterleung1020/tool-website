Contentful 设置向导

按照以下步骤将您的网站升级为 Headless CMS 架构

1

注册 Contentful 账号

访问 Contentful 官网 并注册免费账号。

  • 免费套餐包含 2 个用户
  • 每月 25,000 条 API 记录
  • 支持 5 个空间(Spaces)
  • 无需信用卡
2

创建新空间(Space)

登录后,点击 "Create space" 按钮:

  1. 选择 "Create from scratch"(从头开始)
  2. 输入空间名称,例如: "Tool Website"
  3. 选择区域: "EU (Europe)" 或 "US (North America)"
  4. 点击 "Create space"
提示: 创建完成后,您会看到 Space ID,请记录下来。
3

获取 API 密钥

在空间设置中找到 API Keys:

  1. 点击顶部导航栏的 "Settings" → "API keys"
  2. 点击 "Add API key"
  3. 填写名称(如 "Website Delivery API")
  4. 复制 Space ID 和 Delivery API access token
重要: Delivery Token 是只读的,可以安全地在前端使用。不要使用 Preview Token 或 Management Token!
4

导入内容模型

使用 CLI 工具快速导入预定义的内容模型:

# 安装 Contentful CLI
npm install -g contentful-cli

# 登录
contentful login

# 导入内容模型(在项目根目录执行)
contentful space import --space-id YOUR_SPACE_ID --content-file contentful-model.json

或者手动创建内容模型:

  1. 在 Contentful 界面点击 "Content model"
  2. 点击 "Add content type"
  3. 按照 contentful-model.json 文件中的定义创建字段

配置网站

将您的 API 密钥填入下方,然后点击 "保存配置":

安全提示: 这些信息将保存在浏览器的 LocalStorage 中,仅用于本地开发。生产环境建议使用环境变量。
6

添加内容

配置完成后,进入 Contentful 后台添加您的内容:

  1. 点击 "Content" 标签
  2. 点击 "Add entry" 添加公司信息、轮播图、分类、产品等
  3. 上传图片资源到 "Media" 库
  4. 发布内容(Publish)
完成! 内容发布后,您的网站会自动从 Contentful 读取最新数据。
